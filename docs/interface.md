# Интерфейс (SDUI)

Сервер строит описания форм, списков и навигации из метаданных конфигурации и отбирает их по правам пользователя. Клиент по этим описаниям показывает поля, списки и доступные действия. Он проверяет ввод перед отправкой, а сервер проверяет данные и права при выполнении операции.

Клиент строит стандартные формы записей и списки. Конфигурация может изменить раскладку, подключить собственный элемент или заменить форму целиком. Для собственного экрана конфигурация объявляет страницу, а её компонент входит в сборку клиента.

- [Описания интерфейса](interface/descriptions.md) задают формат ответа `GET /api/metadata`.
- [Оболочка и навигация](interface/shell.md) объясняют, как настроить подсистемы и группы и как работают адреса, вкладки и окна.
- [Формы записей](interface/forms.md) описывают выбор формы, редактирование, проверку и выполнение действий.
- [Списки и ссылки](interface/lists-and-references.md) описывают поиск, отбор, представления записей и переход по ссылкам.
- [Web SDK](web-sdk.md) содержит инструменты для собственных экранов конфигурации, в том числе [поля ввода](web-sdk/fields.md).
