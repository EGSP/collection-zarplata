# Архитектура

Здесь описаны правила учёта зарплаты и продаж магазина, запуск приложения и устройство конфигурации и платформы. Назначение приложения и его возможности изложены в [описании продукта](https://github.com/EGSP/collection-zarplata/blob/main/PRODUCT.md).

## С чего начать

| Задача | Куда перейти |
|---|---|
| Уточнить формулы, округление, условия и запреты магазина | [Правила учёта](accounting-rules.md) |
| Запустить приложение или подготовить поставку | [Сборка и запуск](build-and-launch.md), [поставка](delivery.md) |
| Перенести данные из выгрузки 1С | [Импорт XML из 1С](1c-xml-import.md); об отдельной утилите см. [её руководство](https://github.com/EGSP/collection-zarplata/blob/main/tools/1c-xml-import/README.md) |
| Добавить объект, страницу или элемент формы конфигурации | [Метаданные](metadata.md), [интерфейс и Web SDK](interface.md), [политики записи](write-policies.md) |
| Разобраться в устройстве платформы перед изменением кода | [Принципы](principles.md), затем [структура проекта](project-structure.md); для работы с данными см. [API данных](single-endpoint.md) и [базу данных](database.md) |
| Добавить или переработать страницу документации | [Правила ведения документации](documentation.md) |

## Как найти нужный раздел

Меню слева содержит правила учёта и разделы архитектуры; на узком экране оно открывается кнопкой «Разделы». Поиск в верхней панели находит текст страниц по словам и именам из кода, а оглавление «На этой странице» ведёт к отдельным вопросам внутри страницы.
