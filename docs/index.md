# Архитектура

Приложение для учёта зарплаты и продаж магазина. Документация описывает технические решения: как устроены метаданные, база данных, единый эндпоинт, права, журнал и интерфейс.

Разделы перечислены в меню слева, поиск по тексту — в верхней панели. Начать можно с [принципов](principles.md) и [структуры проекта](project-structure.md).

Формулы, округление и запреты учёта магазина описаны отдельно, в разделе [«Правила учёта»](accounting-rules.md).
