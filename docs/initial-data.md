# Первичные данные

При каждом запуске сервер дополняет базу тем, без чего приложение не работает: создаёт начальных пользователей, загружает справочники из выгрузок 1С, заводит случайных сотрудников и ставку собственной рассрочки. Если любое из условий ниже не выполнено, запуск останавливается.

## Когда применяются первичные данные

Шаги выполняет `InitialDataService.run`. Его вызывает `main.ts` сразу после `listen`, а не хук жизненного цикла Nest: утилита `tools/1c-xml-import` загружает справочники через HTTP API, поэтому сервер к этому моменту уже должен принимать запросы.

```text
NestFactory.create → хуки модулей (метаданные, синхронизация структуры) → listen → run
```

Пока `run` не завершился, сервер отвечает на запросы, но данные в нём неполные. Ошибка любого шага попадает в журнал запуска, сервер закрывается, процесс завершается с кодом `1`: работа с частично загруженными данными не продолжается.

## Порядок шагов

Независимые ветки идут параллельно, зависимые ждут друг друга:

```text
пользователи → ┬ импорт физических лиц → случайные сотрудники
               ├ импорт номенклатуры
               └ ставка собственной рассрочки
```

1. **Пользователи.** Пользователи из `initialUser` файла настроек или из параметров `--test-pin` создаются только в пустой таблице. Без списка `roles` пользователь получает все роли конфигурации. Имена ролей проверяются при каждом запуске, чтобы опечатка не ждала следующей новой базы.
2. **Импорт.** Для сопоставлений `physical-persons` и `nomenclature` сервер запускает утилиту отдельным процессом с параметром `--local-source`. Утилита сама находит в `tools/1c-xml-import/local-source` выгрузки нужного вида. Ей передаются адрес `http://127.0.0.1:<порт>` и PIN начального пользователя через переменную окружения `COLLECTION_IMPORT_PIN`. Повторный запуск обновляет записи по внешним связям и не создаёт дубликатов. Устройство импорта описано в разделе [«Импорт из универсальной XML-выгрузки 1С»](1c-xml-import.md).
3. **Случайные сотрудники.** После загрузки физических лиц сервер выбирает четырёх случайных лиц без пометки удаления и создаёт сотрудников с кодами `000001`–`000004`. Если сотрудники уже есть, шаг ничего не создаёт, иначе файловая база пополнялась бы при каждом запуске.
4. **Ставка собственной рассрочки.** Если в справочнике «Ставки по рассрочке» нет записи «Собственная», сервер создаёт её с процентом 0. Запись с пометкой удаления считается найденной, иначе каждый запуск создавал бы новую. Ставку получает каждая собственная рассрочка, поэтому она должна быть в любой базе. Шаг не зависит от импорта.

Сотрудники и ставка записываются через диспетчер действий: проверяются политики справочника и пишется журнал.

Все шаги, кроме создания пользователей, выполняются от имени начального пользователя со всеми ролями. Пользователь с ограниченными ролями не подходит: у него может не быть прав на запись справочников и внешних связей.

## Условия запуска

| Условие | Сообщение в журнале |
|---|---|
| В настройках есть начальный пользователь без `roles` (`initialUser` или `--test-pin` без ролей) | «Для применения первичных данных нужен начальный пользователь со всеми ролями…» |
| PIN этого пользователя совпадает с сохранённым в базе, и пользователь не отключён | «Начальный пользователь не найден в базе или отключён…» |
| Утилита собрана в `tools/1c-xml-import` по [её руководству](https://github.com/EGSP/collection-zarplata/blob/main/tools/1c-xml-import/README.md) | «Не удалось запустить утилиту импорта…» |
| В `tools/1c-xml-import/local-source` есть выгрузки с физическими лицами и номенклатурой | «Импорт „…“ завершился с кодом 1: …» с текстом ошибки утилиты |
| Сервер слушает loopback-адрес: `127.0.0.1` или `0.0.0.0` | Ошибка соединения утилиты |
| Загружено не меньше четырёх физических лиц без пометки удаления, если сотрудников ещё нет | «Для 4 случайных сотрудников нужно столько же физических лиц…» |

Каталог `local-source` исключён из Git: выгрузки содержат персональные данные. В новом рабочем каталоге его нужно заполнить вручную, иначе запуск, в том числе `npm run start:check`, остановится на шаге импорта.
