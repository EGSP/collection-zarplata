# Структура проекта

Серверный и клиентский код разделены на доменные модули, как в проектах `miracle/back-nest` и `XIP/xip/server`. Пустые пока папки содержат `.gitkeep`.

```
src/
  server/
    main.ts
    application.module.ts
    database/         подключение к Turso, транзакции
    metadata/         DSL описания объектов, реестр объектов конфигурации, билдер и реестр элементов формы
    schema/           сверка метаданных со структурой БД
      migrations/     явные миграции для разрушающих изменений
    data/             единый эндпоинт perform, диспетчер действий, стандартные действия, шаги проведения
    authorization/    RBAC: права из метаданных, роли, бизнес-гвард RightsGuardPlatform и Nest-гвард RightsGuardNest
    authentication/   пользователи, вход по PIN, access- и refresh-токены
    journal/          журнал действий и трассировка
    ui/               построение описаний форм и списков (SDUI), билдер схемы оболочки, билдер и реестр страниц
    settings/         настройки запуска: путь к БД, адрес и порт
    client/           раздача собранного клиента, возврат index.html для маршрутов клиента
    documentation/    раздача собранного сайта документации по адресу /docs
    health/           проверка состояния: сервер запущен, база отвечает
    common/
  configuration/
    catalogs/         *.catalog.ts
    documents/        *.document.ts
    registers/        *.register.ts
    information-registers/  *.information-register.ts
    pages/            страницы: объявление *.page.ts и компонент *.page-component.tsx
    form-elements/    элементы формы: объявление *.form-element.ts и компонент *.form-element-component.tsx
    roles.ts
    shell.ts          схема оболочки: подсистемы, группы, объекты и страницы в них
    configuration.generated.ts   реестр сервера: объекты, объявления страниц и элементов формы, объект прав Rights
    objects.generated.ts         ссылки на объекты для страниц и элементов формы клиента
    pages.generated.ts           реестр страниц клиента: объявления и компоненты
    form-elements.generated.ts   реестр элементов формы клиента: объявления и компоненты
                                 все четыре файла генерируются и исключены из git
  web/
    application/      точка входа, провайдеры Refine, ресурсы из описаний объектов, раскладка со списком подсистем, главный экран, страницы конфигурации
    tabs/             вкладки открытых окон: набор вкладок и его связь с адресом, полоса вкладок, страницы вкладок
    window/           область окна: то, в чём показана страница; вкладка служит её первой реализацией
    authentication/   сессия: вход по PIN, выход, обновление токенов; экран входа; auth provider Refine
    sdk/              web SDK: публичные компоненты и хуки, из которых собираются экраны; точка входа index.ts
    data-provider/    data provider Refine: вызовы /api/perform и /api/metadata, чтение записей пакетом, выполнение действий
    widgets/          реестр виджетов: поля ввода и отображение значений по видам полей, проверка ввода
    references/       ссылки: представление записи, поле выбора записи, ссылка на форму записи
    forms/            страница и форма записи, собранные из SDK; реестр компонентов элементов формы
    lists/            список объекта, собранный из SDK
    keyboard/         менеджер фокуса, горячие клавиши
    common/           клиент API на axios, вид ошибок запросов, адреса страниц, общие компоненты
docs/                 разделы архитектуры в Markdown и настройка сайта документации (.vitepress)
scripts/              служебные скрипты: генерация реестров, проверка импортов клиентских файлов конфигурации, сборка исполняемого файла
repos/                исходники внешних библиотек (git subtree), только для чтения
```
