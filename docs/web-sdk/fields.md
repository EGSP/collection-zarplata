# Поля ввода Web SDK

`FieldInput` выбирает ввод по `FieldKind`, `FieldDisplay` выводит значение для чтения. [Реестр виджетов](https://github.com/EGSP/collection-zarplata/blob/main/src/web/widgets/registry.tsx) сопоставляет каждому виду обе реализации. Одни компоненты используются в формах, табличных частях, отборах и окнах действий.

В форме значение хранится в формате API. Деньги передаются в копейках, даты строками ISO, простая ссылка хранит `guid`, пустое значение представлено `null`. Виджет преобразует ввод в этот формат. Собственный элемент поля соблюдает [контракт элемента формы](../metadata.md#контракт-элемента), в том числе принимает фокус для клавиатурного обхода.

Если набранная дата выходит за допустимые границы или имеет неверный формат, виджет сохраняет текст для исправления. Пока в поле есть ошибка, форма блокирует запись и проведение. Последнее корректное значение остаётся значением поля.

## Поле ссылки

Поиск использует представление записи. Подсказки исключают помеченные на удаление записи. Существующую ссылку на такую запись можно прочитать. Когда объект недоступен, поле показывает «Нет доступа».

Если по тексту нет совпадений, поле предлагает создание записи при наличии права записи и области окна. Записанная запись становится значением поля. Справочник с собственным наименованием получает введённый текст как начальное значение. При закрытии окна без записи поле сохраняет прежнее значение. Переход по ссылке следует [правилу открытия записи](../metadata.md#правило-открытия-записи).

## Составное поле

[Составное поле](../metadata.md#составное-поле) хранит значение вместе с типом. Сервер передаёт допустимые варианты и `inputMode`. `fluent` использует одно поле текста с подсказками. `solid` сначала предлагает тип, затем поле этого вида. Стандартный виджет показывает конкретный тип значения и в режиме просмотра.

### Текстовый ввод (`fluent`)

При наличии строкового варианта введённое «100» становится строкой. Чтобы получить число, выберите подсказку «Число: 100». `Enter` без выделенной подсказки сохраняет результат текстового ввода. Подсказки содержат подходящие записи ссылочных объектов, значения строкового перечня и возможные толкования текста.

При правке текущий тип сохраняется, пока текст ему соответствует. Если строкового варианта нет, число или сумма принимаются при корректном формате. Допустимы десятичная точка либо запятая и пробелы между разрядами. Сумма принимает до двух десятичных знаков, целое число принимается без дробной части. Текст, который не стал значением простого типа, служит поиском подсказок. Очистка возвращает `null`.

Если ни одной записи по тексту не найдено, можно создать её в одном из доступных для записи справочников. Сохранённая запись заменяет введённый текст. Это тот же механизм, что в [поле ссылки](#поле-ссылки).

### Выбор типа (`solid`)

Сначала выберите тип, затем введите значение или выберите запись. Смена типа очищает прежнее значение. `.inputMode('solid')` позволяет задать этот режим в метаданных. На экране можно передать `inputMode="solid"` в `FieldInput`. Возможность текстового ввода определяет платформа по [вариантам поля](../metadata.md#способ-ввода).

Собственный компонент, заменяющий ввод составного поля, получает режим в `field.inputMode`. Чтобы поддержать оба режима, передайте значение в `FieldInput` или используйте реализацию из `compositeInputs`. Оба компонента принимают `CompositeInputProperties`.

## Подсказки и вычисляемые поля

Поле ссылки и составное поле читают подсказки через `useRecordSuggestions`. При открытом списке хук ждёт 300 мс после ввода, затем отправляет один пакет `list` для доступных объектов. По каждому объекту он запрашивает до 20 записей в порядке сортировки по умолчанию.

У числового поля с `suggestions` свой источник. Оно предлагает до 50 записей с представлением и числом, а выбор сохраняет только число. Пустые значения источника и помеченные записи исключаются.

Вычисляемое поле показывает результат только для чтения. При изменении значений форма пересчитывает строки частей, затем шапку. Сервер применяет те же формулы при проверке и сохранении.
