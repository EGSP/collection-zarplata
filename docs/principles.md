# Принципы

- **Модельно-ориентированная разработка (MDD).** Прикладные объекты (справочники, документы, регистры) описываются декларативно. По описанию платформа строит структуру БД, API, права, валидацию и формы.
- **Платформа отделена от конфигурации.** Платформа — это механизмы: хранение, единый API, права, журнал, SDUI. Конфигурация — это прикладные объекты и роли конкретного магазина. Новый объект добавляется одним файлом конфигурации без ручной регистрации.
- **Один процесс, один исполняемый файл.** NestJS обслуживает API и раздаёт собранный фронтенд. Файл БД лежит рядом с исполняемым файлом.
- **Effect только в бизнес-логике.** Роутинг, контроллеры и DI остаются на Nest. Effect управляет ходом выполнения: ошибками, транзакциями, контекстом действия, композицией операций.
- **Полные имена.** В идентификаторах, действиях, маршрутах и полях используются полные слова без сокращений: `parameters`, а не `params`; `configuration`, а не `config`. Допустимы только общепринятые аббревиатуры: `guid`, `API`, `UI`, `SQL`, `JSON`.
