# Принципы

## Платформа и конфигурация

Платформа реализует общие механизмы: хранение, [API данных](single-endpoint.md), [права](authorization.md), [журнал действий](journal.md) и [интерфейс по серверным описаниям](interface.md). Конфигурация задаёт объекты, роли и бизнес-правила конкретного магазина. Состав объектов меняется в конфигурации, общие механизмы меняются в платформе.

Объекты описываются декларативно. Подход модельно-ориентированной разработки (MDD) связывает структуру базы, действия API, права, проверку данных и стандартные формы через единые метаданные: разработчик описывает объект один раз, а каждый механизм платформы читает это описание.

Новый объект добавляется файлом конфигурации без ручной регистрации. При сборке генератор находит файлы по соглашению и составляет реестр; подробности в разделе [«Метаданные»](metadata.md).

## Процесс и поставка

Собранное приложение работает как один серверный процесс NestJS: он обслуживает API и раздаёт клиент браузерам. Поставка для Windows упаковывает сервер и клиент в один исполняемый файл. Настройки и база остаются отдельными файлами.

Путь базы задаёт параметр `databasePath` в настройках. Относительный путь отсчитывается от каталога настроек, абсолютный тоже допустим, поэтому база не обязана лежать рядом с исполняемым файлом.

Упаковка описана в разделе [«Поставка»](delivery.md), режим разработки и проверка на базе в памяти в разделе [«Сборка и запуск»](build-and-launch.md).

## Effect и NestJS

Effect применяется в бизнес-логике: для композиции операций, обработки ошибок, транзакций и контекста действия. Роутинг, контроллеры и внедрение зависимостей остаются на NestJS. Контроллер принимает HTTP-запрос и передаёт его сервису, а сервис запускает программу Effect. Подробнее: [«API данных»](single-endpoint.md) и [«База данных»](database.md).

## Именование

В идентификаторах, действиях, маршрутах и полях пишут полные слова: `parameters`, а не `params`; `configuration`, а не `config`. Сокращаются только общепринятые аббревиатуры: `guid`, `API`, `UI`, `SQL`, `JSON`.
