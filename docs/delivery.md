# Поставка

- Для сборки на Windows x64 нужен Node.js 24.8 или новее, npm и установленные зависимости (`npm ci`). Выполните `npm run build:executable`, скопируйте `dist/executable/collection-zarplata.exe` в каталог поставки, рядом создайте `collection-zarplata.settings.json` по образцу и запустите `.exe`. На целевой машине Node.js и `node_modules` не нужны.
- Используется Node SEA: esbuild собирает NestJS и зависимости в один сценарий, Vite собирает клиент, VitePress — сайт документации, SEA встраивает сценарий, файлы клиента, файлы сайта документации и нативный модуль Turso в копию Node.js. При запуске нативный модуль извлекается в каталог `%TEMP%/collection-zarplata/` по хешу содержимого. Файлы клиента и сайта документации отдаются непосредственно из ресурсов исполняемого файла.
- Проверен также `bun build --compile`: он собрал каркас после исключения необязательных интеграций NestJS, но полученный файл не смог загрузить нативный модуль `@tursodatabase/database`. Поэтому для этой поставки выбран Node SEA.
- Файл БД создаётся по пути `databasePath` из настроек. По умолчанию в образце он лежит рядом с исполняемым файлом.
- Резервная копия — копия файла БД.
